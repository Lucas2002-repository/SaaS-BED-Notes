Assessment Summary

Assessment Task 1

Assessment Title: Knowledge Assessment – Enterprise API Engineering

Brief Description:

This is an in-class, supervised, open-book theory assessment covering the knowledge evidence for ICTPRG553 and ICTPRG554.

The assessment evaluates students’ understanding of:

* REST architecture and RESTful design principles
* HTTP methods, status codes and headers
* API authentication and authorisation
* API documentation and OpenAPI specifications
* Enterprise API architecture
* NoSQL concepts and data modelling
* Selection of relational and NoSQL databases
* Enterprise integration concepts
* Software engineering best practices

Due Date

Week 8 (Session 8)

Assessment Hours

2 Hours

⸻

Assessment Task 2

Assessment Title: Enterprise API Analysis and Reverse Engineering Project (No AI)

Brief Description:

Students will analyse the published MyJamJar Enterprise API without access to the source code.

Working from the supplied API documentation, OpenAPI specification, Postman Workspace, Collections and business requirements, students will investigate the enterprise platform and produce technical documentation demonstrating their understanding of the system architecture.

Deliverables include:

* API resource analysis
* Endpoint catalogue
* Authentication analysis
* UML diagrams
* Data models
* Architecture documentation
* Enterprise design recommendations

Students must also successfully complete an individual validation interview to demonstrate ownership of their work and justify their engineering decisions.

Due Date

Project Submission – Week 16

Validation Interviews – Commencing Week 17

Assessment Hours

Approximately 24–30 Hours

⸻

Assessment Task 3

Assessment Title: Enterprise API Enhancement Project (AI Permitted)

Brief Description:

Students will design and implement an enhancement to the enterprise API using professional software engineering practices.

Possible enhancement areas include:

* New REST endpoints
* External system integration
* Background processing
* Reporting services
* File attachment management
* NoSQL persistence
* Search functionality
* Enterprise workflow improvements

Students are expected to use AI responsibly as a professional engineering assistant while maintaining responsibility for all architectural decisions, implementation quality and testing.

Deliverables include:

* Source code
* Technical documentation
* Updated API documentation
* Testing evidence
* AI usage record
* Demonstration of the completed enhancement

Due Date

Weeks 19–20

Assessment Hours

Approximately 40 Hours
